# 🎨 Paper2Project — Frontend Application

This is the Next.js 16 frontend for **Paper2Project**, an AI platform converting research ideas into working implementations.

## Features
- **Vibrant Light Colorful UI**: Modern aesthetics with Tailwind CSS v4 and glassmorphism.
- **Universal Ingestion**: Paste ideas or upload PDF, DOCX, or text files.
- **Literature Overlap Matrix**: Categorizes features into Fully Implemented, Partially Explored, or Novel.
- **Questionnaire Roadmap**: Interactive planner calibrating time, equipment, and $0 budget.
- **Dual-Pane Copilot**: Project-grounded AI assistant with syntax-highlighted code blocks and copy buttons.
- **Interactive React Flow**: System and data pipeline diagrams.

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Building for Production

```bash
npm run build
npm start
```
